Factory Inventory Management System

System architecture, technology stack, and data flow — demo application with in-memory mock data.

Vue 3 + Vite FastAPI No Database Local Dev Only

Tech Stack

Frontend — client/

  • Vue 3 (Composition API) ^3.4
  • Vite dev server, port 3000
  • Vue Router ^4.3, client-side routing
  • Axios ^1.6, HTTP client

Backend — server/

  • FastAPI Python, port 8001
  • Pydantic request/response models
  • Uvicorn ASGI server
  • uv dependency manager

Data — server/data/

  • JSON files inventory, orders, spending…
  • mock_data.py loads JSON at startup
  • In-memory only no persistence
  • generate_data.py sample data generator

Request / Filter Data Flow

Vue view sets filters
(warehouse, category, status, month)
→
api.js builds query params
and calls axios.get(...)
→
FastAPI route applies
apply_filters() / filter_by_month()
→
Pydantic validates &
shapes the response
↓
Vue computed properties derive dashboard totals, charts, and tables from the raw response — raw data stays in refs (allOrders, inventoryItems), derived values stay in computed properties.
